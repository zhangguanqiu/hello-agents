# CVM服务器成本优化智能体系统

基于 AutoGen 框架的多智能体协作系统，用于云服务器成本优化评估。

## 系统架构

### 智能体角色

1. **成本智能体 (ProductManager)**
   - 根据CPU和内存使用率分析当前配置
   - 推荐最优的机型配置
   - 根据评估反馈调整推荐方案

2. **稳定性智能体 (Engineer)**
   - 评估推荐配置的性能容量
   - 确保至少保留20%资源余量
   - 预测系统运行稳定性

3. **安全智能体 (CodeReviewer)**
   - 评估配置变更的安全影响
   - 确保不引入新的安全风险
   - 检查合规性

4. **决策智能体 (FinalDecisionAgent)**
   - 汇总所有评估结果
   - 做出最终决策（allow: true/false）
   - 只有当稳定性和安全评估都通过时才允许变更

## 工作流程

```
┌─────────────────────────────────────────────────────────┐
│                    第 N 轮评估                           │
├─────────────────────────────────────────────────────────┤
│                                                          │
│  1. 成本智能体 → 分析并推荐机型                         │
│         ↓                                                │
│  2. 稳定性智能体 → 评估性能和稳定性                     │
│         ↓                                                │
│  3. 安全智能体 → 评估安全风险                           │
│         ↓                                                │
│  4. 决策智能体 → 综合评估，输出 allow 决策              │
│                                                          │
├─────────────────────────────────────────────────────────┤
│                                                          │
│  如果 allow = true  → ✅ 评估通过，采纳方案             │
│  如果 allow = false → ❌ 进入下一轮，反馈问题给成本智能体│
│                                                          │
└─────────────────────────────────────────────────────────┘
```

## 评估规则

### 成本智能体规则

1. CPU使用率在40%-70%，内存使用率在40%-90%，则保持不变
2. CPU需求核数 = ceil(当前核数 × CPU使用率)
3. 内存需求容量 = ceil(当前内存 × 内存使用率)
4. 推荐机型的CPU规格必须大于CPU需求核数
5. 推荐机型的内存规格必须大于内存需求容量

### 稳定性评估标准

- 新配置应至少保留20%的资源余量应对突发负载
- 评估配置变更对系统稳定性的影响

### 安全评估标准

- 确保配置变更不会引入新的安全风险
- 检查是否符合安全最佳实践

## 使用方法

### 1. 环境配置

创建 `.env` 文件：

```bash
LLM_MODEL_ID=your-model-id
LLM_API_KEY=your-api-key
LLM_BASE_URL=your-base-url
LLM_TIMEOUT=60
```

### 2. 安装依赖

```bash
pip install autogen-agentchat autogen-ext python-dotenv
```

### 3. 运行系统

```bash
python assest.py
```

### 4. 自定义任务

修改 `initial_task` 变量中的参数：

```python
initial_task = """# CVM服务器成本优化分析任务
当前机型规格和价格：32核128G的IT5.8XLARGE128价格4694.4
目前CPU使用率:2.2%
目前CPU核数:32
目前MEM使用率: 60.27%
目前内存大小（GB）:128
变更的目标机型规格和价格列表：
16核64G的IT5.4XLARGE64价格2347.2
32核128G的IT5.8XLARGE128价格4694.4
64核256G的IT5.16XLARGE256价格9388.8
84核320G的IT5.21XLARGE320价格11541.6"""
```

## 核心特性

### 1. 迭代优化机制
- 支持最多3轮评估
- 每轮根据反馈调整方案
- 自动终止条件：所有评估通过

### 2. 智能反馈系统
- 稳定性问题自动反馈给成本智能体
- 安全问题自动反馈给成本智能体
- 成本智能体根据反馈调整推荐

### 3. 清晰的输出格式
- 使用 emoji 增强可读性
- 分阶段显示评估结果
- 明确显示反馈和调整过程

### 4. 健壮的JSON解析
- 支持流式输出的JSON解析
- 处理布尔值和字符串混合情况
- 从消息对象直接提取数据

## 技术亮点

1. **AutoGen RoundRobinGroupChat**：轮询式团队对话
2. **TextMentionTermination**：基于关键词的终止条件
3. **流式输出处理**：实时显示智能体对话
4. **正则表达式JSON提取**：健壮的数据解析
5. **迭代反馈机制**：智能体间的协作优化

## 故障排查

### 问题：评估一直不通过
- 检查机型列表是否包含合适的配置
- 查看稳定性评估的具体原因
- 考虑调整资源使用率参数

### 问题：JSON解析失败
- 确保LLM模型支持JSON输出
- 检查模型的temperature设置（建议为0）
- 查看智能体的system_message是否明确要求JSON格式

### 问题：循环次数过多
- 检查max_iterations设置
- 查看反馈信息是否被正确传递
- 确认决策智能体的allow逻辑
